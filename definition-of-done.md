# Definition of Done

**Quality Agreement & Simulation Boundaries**

*   **Code Quality:** No syntax errors. Code is modular with a clear separation between calculation logic and UI (CLI).
*   **Error Handling:** The application must never crash with a raw Python traceback when a user types letters instead of numbers.
*   **Accuracy:** The mathematical output is strictly correct according to c = √(a² + b²).
*   **Peer Review:** Code must be reviewed (or self-reviewed via a structured checklist) before merging to the `main` branch.
*   **Documentation:** `README.md` is updated and reflects the current state of the application.
